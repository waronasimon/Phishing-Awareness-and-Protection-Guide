# Phishing Awareness and Defense Guide

A comprehensive open-source guide to help individuals and small teams identify, prevent, and respond to phishing attacks.

This repository was created for cybersecurity awareness training and is designed to be simple, practical, and actionable.

### 🎯 Project Overview
Phishing remains the #1 attack vector for data breaches. This guide teaches non-technical users how to spot phishing emails, SMS (smishing), and calls (vishing) before they cause damage.

**Objectives:**
- Explain what phishing is and why it works
- Provide clear red flags to spot phishing
- Outline exactly what to do if you are phished
- Give ready-to-use reporting templates and posters for the office

### 📁 What's Inside

- **docs/01-what-is-phishing.md** - Types of phishing and real-world examples
- **docs/02-how-to-spot-phishing.md** - 10 red flags checklist
- **docs/03-what-to-do-if-phished.md** - Immediate response steps
- **templates/phishing-report-template.md** - Template to report suspicious emails to IT
- **assets/phishing-red-flags-poster.md** - Printable office poster

### 🚀 How to Use

1.  Start with `docs/01-what-is-phishing.md`
2.  Learn the red flags in `docs/02-how-to-spot-phishing.md`
3.  Save `templates/phishing-report-template.md` for your team
4.  Print `assets/phishing-red-flags-poster.md` for your office

### 🛡️ Key Message
**Stop-Look-Think**Before you click, verify the sender. hover over links   and report anything suspicious.
