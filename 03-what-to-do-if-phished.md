# What To Do If You Are Phished

### If you CLICKED:
1. Disconnect from internet immediately
2. Do NOT enter more valuable info
3. Change password from a clean device
4. Enable multi-factor authentication 
5. Run antivirus scan
6. Report to IT / helpdesk

### If you ENTERED credentials:
1. Change password EVERYWHERE you reused it
2. Contact bank if you gave financial info
3. Report to your IT team using the template in /templates/

### Reporting:
- Forward email as attachment to IT
- Don't delete evidence
- Warn colleagues
